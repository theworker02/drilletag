# drilletag

Drill HTML/Markdown etag fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/drilletag/

## Install / run

```bash
git clone https://github.com/theworker02/drilletag.git
cd drilletag
node src/cli.js
node --test
```
